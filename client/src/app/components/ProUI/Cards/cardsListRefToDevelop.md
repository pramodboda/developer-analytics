## Common UI Card types

| Card name               | Typical purpose                | Example                  |
| ----------------------- | ------------------------------ | ------------------------ |
| **Content Card**        | General information            | Article preview          |
| **Info Card**           | Displays information           | User details             |
| **Stat Card**           | Shows a single metric          | `Total Users: 24,580`    |
| **KPI Card**            | Important business metric      | `Revenue: ₹12.4L ↑ 14%`  |
| **Metric Card**         | Displays a measurable value    | `CPU: 68%`               |
| **Summary Card**        | Quick summary                  | Project overview         |
| **Dashboard Card**      | Generic dashboard component    | Sales overview           |
| **Data Card**           | Structured data                | Customer information     |
| **Profile Card**        | Person/user information        | Avatar + name + role     |
| **Product Card**        | Product information            | Image + price + rating   |
| **Feature Card**        | Highlights a feature           | AI-powered analytics     |
| **Action Card**         | Encourages an action           | “Create Project”         |
| **CTA Card**            | Call-to-action                 | “Upgrade Plan”           |
| **Notification Card**   | Notification/message           | “Deployment completed”   |
| **Alert Card**          | Warning/error/important notice | “API usage is 90%”       |
| **Status Card**         | Current state                  | `Server: Healthy`        |
| **Activity Card**       | Recent activity                | “John updated Project X” |
| **Timeline Card**       | Event/history item             | `10:30 AM — Deployment`  |
| **Task Card**           | Task/todo                      | “Fix authentication bug” |
| **Event Card**          | Event information              | Meeting / conference     |
| **Chart Card**          | Chart inside a card            | Revenue chart            |
| **Analytics Card**      | Analytics/insights             | Conversion rate          |
| **Progress Card**       | Progress toward a goal         | `75% completed`          |
| **Comparison Card**     | Compare values                 | This month vs last month |
| **Trend Card**          | Metric + trend                 | `Users ↑ 18%`            |
| **Insight Card**        | AI/business insight            | “Traffic increased 23%”  |
| **Recommendation Card** | Suggested action/content       | “Optimize API queries”   |
| **Warning Card**        | Potential problem              | “Storage almost full”    |
| **Error Card**          | Error state                    | “Unable to load data”    |
| **Empty State Card**    | No data                        | “No projects yet”        |
| **Loading Card**        | Loading placeholder            | Skeleton UI              |
| **Expandable Card**     | Can expand/collapse            | Details panel            |
| **Interactive Card**    | Clickable/interactive          | Select a project         |
| **Selectable Card**     | User selects an option         | Pricing plan             |
| **Navigation Card**     | Links to another area          | Dashboard → Analytics    |
| **Media Card**          | Image/video + content          | Portfolio project        |
| **Article Card**        | Article/news preview           | Blog                     |
| **Testimonial Card**    | Customer testimonial           | Quote + avatar           |
| **Pricing Card**        | Pricing/plan                   | Free / Pro / Enterprise  |
| **Login/Auth Card**     | Authentication UI              | Login form               |
| **Form Card**           | Form contained in card         | Create user              |
| **Settings Card**       | Settings section               | Notification settings    |
| **Filter Card**         | Filtering controls             | Date + status + region   |
| **Search Card**         | Search interface               | Search users             |
| **Table Card**          | Table contained in card        | User list                |
| **List Card**           | List of items                  | Recent orders            |
| **Command Card**        | Quick commands/actions         | Admin shortcuts          |
